# 🐝 BeeLab Management — Цифрова пасіка

**BeeLab** — це сучасна SaaS-платформа для професійних пасічників, розроблена для автоматизації обліку, моніторингу та планування робіт на пасіці. 

## 🚀 Основні можливості
* **Цифровий журнал оглядів**: Повна історія кожного вулика з відстеженням рівня меду та стану сім'ї.
* **Telegram-інтеграція**: Персональні ранкові звіти з планом робіт на день прямо у ваш месенджер.
* **Аналітика та Статистика**: Відстеження критичних станів (маточники, старі матки) у реальному часі.
* **Розумний календар**: Автоматичне планування завдань після оглядів (підгодівля, зняття пластин тощо).
* **Метеодані**: Локальний прогноз погоди для вашої пасіки в профілі користувача.

## 🛠 Технологічний стек
* **Backend**: Python 3.11, Flask
* **Database**: MySQL 8.0
* **Frontend**: Bootstrap 5.3, Jinja2
* **Infrastructure**: Docker, Docker-Compose
* **Automation**: APScheduler (для Telegram-розсилок)
